# Free Hobby Starter Kit

Six print-at-home starter kits for hobbies that cost (almost) nothing to begin
— no gear, no apps, no purchases. Each kit is a friendly short read for the
grown-up followed by ready-to-write planner pages, and every kit builds into
clean, unbranded PDFs you can print at home.

Bird-watching, stargazing, sketching, hiking, board games you already own, and
letter writing — the only supply each asks for is a pencil and a bit of
attention.

Made by [Asdale Dynamics, LLC](https://dylanasdale.github.io) — AI education
and practical tools, explained like a friend would.

## What's inside

| Sheet | Pages | What it gives you |
|---|---|---|
| Bird-Watching | 3 | Grown-up intro, spotting log with weather + behavior notes, six-week streak chart & first-find checklist |
| Stargazing Night | 3 | Grown-up intro, one-night sky plan card with treasure hunt + constellation sketch, season night log |
| Sketching | 3 | Grown-up intro, thirty tiny five-minute prompts, two-frame prompt diary page |
| Hiking | 3 | Grown-up intro, mile log with "best moment" column, twelve-trail progress page |
| Board Games We Own | 3 | Grown-up intro, shelf inventory with honest verdicts, game-night helper with house-rule log |
| Letter-Writing Kit | 4 | Grown-up intro, stationery sheet with writing lines, trace-and-cut envelope template, correspondence log |

Every sheet starts with a parent/adult intro page: how to hand the hobby over,
what to say in the first five minutes, and what *not* to buy. The printable
pages themselves carry no branding, so they pass on to anyone.

## Quick start

Requirements: Python 3.10+, then two pip packages.

```bash
pip install -r requirements.txt
python3 build.py
```

Six PDFs appear in `printables/`. Print them on US Letter paper at
"Actual size" (not "Fit to page") so the writing lines land where they should.

Build a single sheet: `python3 build.py --sheet birdwatching`

## Run the tests

```bash
python3 -m unittest discover tests -v
```

The test suite builds every sheet from scratch and verifies:

- every expected hobby source exists and produces a PDF,
- each PDF has the expected page count (a page overflowing its section is the
  kind of layout bug these tests are designed to catch),
- every page is Letter portrait and extracts real text (no blank pages).

## Layout

```
sources/              HTML sources, one file per hobby + shared assets/style.css
sources/assets/       one shared print stylesheet (Letter, printer-friendly inks)
printables/           built PDFs (regenerated by build.py, safe to delete)
tests/                build + PDF validation tests
build.py              the one build script
```

## Adding a hobby

A sheet is just an HTML file in `sources/` using the shared classes:
`.page` (one printed page each), `table.log` (write-in tables),
`.checklist`, `.tipbox`, `.sketch-frame`, `.columns`.

Rules of the kit: page 1 is always the grown-up intro, every page must fill
exactly one printed sheet, and nothing on the pages may require buying gear.
Then add the filename and page count to `EXPECTED_SHEETS` in
`tests/test_build.py` so the build stays verified.

## Local-first

This project runs entirely on your machine: no accounts, no network calls
during build, no telemetry, no secrets or personal data. Everything that
happens happens in this folder.
